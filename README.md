# Анастасия — подбор няни

Рабочий сайт: https://nastya-nanny-concepts-oct23.dusky-brumm.chatgpt.site/

Библиотека рисунков: https://nastya-nanny-concepts-oct23.dusky-brumm.chatgpt.site/artwork

С 7 ноября 2026 опубликована одна выбранная пользователем сборка из девяти блоков. Каждый блок редактируется в отдельном HTML в src/site/blocks. Состав и происхождение блоков зафиксированы в src/site/selection.json. Старые варианты остались в исходниках и истории Git, а их страницы исключены из публикации.

Для работы: npm run build, npm run check, npm test. Сборка создаёт out и ZIP из 115 сохранённых рисунков. Каталог рисунков: src/site/artwork, метаданные: src/site/artwork-catalog.json. Подробности выбора и проверки: docs/selected-base-20261107.md. Предыдущая документация: docs/readme-before-selected-base-20261107.md.

Форма сохраняет выбранное поведение: подготавливает черновик в браузере для самостоятельной отправки в Telegram. Фотографии, условия, контент и выбранная палитра сохранены.

Для выбора единой типографики возвращены все прежние шрифты: 20 готовых пар и независимый выбор заголовков/текста позволяют собрать 100 сочетаний. Пара применяется ко всем блокам и сохраняется в ссылке `?fonts=1…100`. Подробности: docs/historical-fonts-20261107.md. Отзывы размещены по три карточки на компьютере, в заявке восстановлен конверт, стоимость имеет молочный фон; история правок: docs/type-and-texture-20261107.md.
