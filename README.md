# Анастасия — пять новых дизайнов сайта

[Открыть новую галерею](https://dusky-brumm.github.io/anastasia-nanny-concepts/next.html).

Пять новых полных композиций по текстовому брифу и обратной связи клиентки. В каждой — одна последовательность из девяти блоков, профессиональный русский текст, реальные фотографии и отзывы. Основной контент ограничен шириной 1120 px. На широком экране остаются поля, на телефоне сетки перестраиваются.

| Вариант | Композиция |
| --- | --- |
| `01-air` — Голубая обложка | Центрированный заголовок, горизонтальная фотография и открытый маршрут |
| `02-column` — Редакционный сайт | Боковое меню и узкая колонка для чтения |
| `03-practice` — Практичный сервис | Пример интервью под вакансию и сравнение двух форматов работы |
| `04-portrait` — Портрет и текст | Крупный портрет и отдельная светлая панель с перекрытием |
| `05-album` — Семейный альбом | Три фотографии, цельное описание услуги и раскрывающиеся этапы |

Галерея переключает превью компьютера и телефона, сохраняет избранное и открывает полноценные страницы. У каждого варианта есть ссылки на полные скриншоты обоих размеров. Избранное новой серии отделено от прежних вариантов идентификаторами с префиксом `next-`; ранее сохранённые варианты сохраняются.

## Файлы и предыдущие серии

- `src/next/` — каталог, содержание, пять независимых композиций и шаблон галереи.
- `dist/next.html` — новая галерея; `dist/next/*.html` — пять сайтов.
- `dist/next/` — общая основа, отдельные стили пяти страниц и интерфейс.
- `dist/next/previews/` и `screens/` — превью и полные скриншоты настоящих страниц.
- `dist/next/fonts/` — локальные Golos Text и Lora с лицензиями OFL. В новой серии нет загрузки шрифтов с внешних сервисов.
- `dist/next/media/cafe-story.webp` — облегчённая копия предоставленного снимка; остальные фотографии — в `dist/assets/`.
- `dist/atelier.html` — предыдущие шесть; `restart.html` — предыдущие три; `all.html` — архив ранних вариантов. Сохранены и старые ссылки `index.html?concept=air|editorial|warm`.

Фотографии из предоставленных материалов опубликованы с разрешения пользователя. Стоимость и условия в макетах требуют окончательного согласования перед рабочим запуском.

## Формы и взаимодействия

Форма проверяет поля и готовит текст заявки в браузере. Пользователь копирует его и самостоятельно отправляет Анастасии в Telegram. Автоматической отправки, хранения контактных данных и аналитики нет. Без скрипта кнопка формы отключена, чтобы контактные данные не попадали в URL статического хостинга. Изменение полей скрывает устаревший черновик.

Выбор формата переносится в форму. Примеры интервью и форматы поддерживают клавиатуру; содержание обоих вариантов присутствует в HTML до запуска скрипта. Результаты всех пяти этапов в альбоме видны даже при закрытых деталях. Предусмотрены меню, диалог о данных формы, видимый фокус и системное уменьшение движения.

Для подключения настоящего получения заявок понадобятся серверный обработчик и согласованные документы об обработке данных.

## Локальная работа и проверка

Нужны Node.js 20+ и Python 3. Зависимости npm не требуются.

```sh
npm run build
python -m http.server 4191 --bind 127.0.0.1 --directory dist
```

Открыть `/next.html`. Генератор сохраняет стили и исходные файлы в `dist/`, создавая HTML из модулей `src/`. После крупных изменений и перед push:

```sh
npm run check
npm test
git diff --check
```

Статическая проверка охватывает локальные ссылки, изображения, подписи полей, HTML/CSS и синтаксис JavaScript. Тесты проверяют состав новых страниц, область действия гарантий, исходное содержание переключателей, сохранность заявки и избранного. Визуальные и интерактивные проверки выполняются отдельно в браузере.

Все пять новых страниц прошли полный цикл скриншотов компьютера и телефона, независимой критики и исправлений с повторной съёмкой. Дополнительно проверяются ширины 320/390/768/1440/1920/2560 px, формы, меню, клавиатура, этапы и галерея. Исходные PNG, разборы и журналы хранятся локально в игнорируемой папке `project-notes/next-2026-10-30/`.

`scripts/prepare-next-previews.py <папка-съёмки> --export` проверяет полноту PNG по геометрии браузера и готовит WebP для галереи; нужен Pillow. `?capture=1` отключает движение и фиксирует боковое меню только на время съёмки.

GitHub Pages публикуется из корня ветки `codex/github-pages`, получаемой через `git subtree split --prefix=dist`. Исходники находятся в `main`. Настройки существующего частного Site сохраняются отдельно в `.openai/hosting.json`.
