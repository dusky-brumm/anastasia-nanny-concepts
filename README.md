# Анастасия — итоговый сайт

Рабочий адрес: https://nastya-nanny-concepts-oct23.dusky-brumm.chatgpt.site/

С 8 ноября 2026 это один зафиксированный сайт из девяти блоков. Выбранные шрифты — Lora для заголовков и Manrope для текста; знакомство с Анастасией — первый молочный разворот. Переключателей оформления, шрифтов и отдельной библиотеки рисунков больше нет. Старые параметры `fonts` и `about` не меняют сайт.

Каждый блок редактируется в отдельном HTML в `src/site/blocks`. Порядок блоков и происхождение выбранной сборки записаны в `src/site/selection.json`. Общая типографика — `src/site/typography.js` и `site-typography.css`; окончательные правки оформления — `site-refinements.css` и `site-polish.css`. Тексты и фотографии знакомства — `blocks/about.html`, поведение слайдера — `about-story.js`.

Форма готовит черновик в браузере для самостоятельной отправки в Telegram. Публичные взаимодействия меню отделены от прежнего конструктора. Рисование линий и иллюстраций сохранено; системное уменьшение движения учитывается.

Светлые поверхности используют единый молочный цвет `#faf8f2` из `--site-milk` в `site-typography.css`. Контур основных кнопок задан в последнем слое `site-polish.css` отдельно от заливки.

Команды: `npm run build`, `npm run check`, `npm test`. Сборка создаёт `out` только из зависимостей итоговых блоков. Галерея, архив рисунков, неиспользуемые картинки и код конструктора в публикацию не попадают. `src/site/artwork-catalog.json` — внутренний список оставшихся канонических элементов, включая SVG, которые встраиваются прямо в HTML.

История прежних экспериментов остаётся в Git и архивных исходниках `src/reference`; их страницы и генераторы не публикуются. Текущая передача сайта описана в `docs/final-site-20261108.md`.
