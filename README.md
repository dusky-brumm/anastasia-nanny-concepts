# Настя — подбор нянь

[Открыть страницу](https://dusky-brumm.github.io/anastasia-nanny-concepts/).

Одна страница по предоставленному 2 ноября образцу: первый экран с фотоколлажем и запиской, отзывы, рассказ об Анастасии, маршрут подбора и контакты. Цвета, тексты, цифры и композиция воспроизведены из этого образца. На компьютере ширина контента ограничена 1120 px; на телефоне блоки перестраиваются в одну колонку.

[Четыре варианта маршрута](https://dusky-brumm.github.io/anastasia-nanny-concepts/routes.html) показаны на отдельной странице сравнения. Первый повторяет новый образец с голубыми номерами и петляющими стрелками; остальные — одна линия, две строки и карточки-записки. Кнопка каждого варианта открывает его внутри сайта через `?route=1`, `2`, `3` или `4`. По умолчанию используется первый. Маршрут — HTML с упорядоченным списком и векторные SVG-стрелки; на узком экране сохраняется порядок этапов 1–5. `src/reference/journeys.js` содержит общий текст и композиции, `journeys.css` — их стили, `routes.html` и `routes-gallery.css` — страницу сравнения.

## Исходники и публикация

- `src/reference/` — HTML, CSS, JavaScript, локальные шрифты и изображения новой страницы.
- `out/` — результат сборки и единственная публикуемая директория.
- `scripts/build-reference.mjs` — сборка с версией стилей и скриптов по хешу исходников.
- `.openai/hosting.json` — сохранённая идентичность частного Site и директория публикации.

Старые исходники, материалы и локальные архивы сохранены. Галереи прежних вариантов не входят в новую публикацию. Ссылка `/next.html` перенаправляет на новую главную страницу. GitHub Pages публикуется из корня ветки `codex/github-pages`; её дерево берётся из `HEAD:out`. Исходники находятся в `main`.

Коллажи фотографий, записка и цветочные украшения вырезаны из предоставленного образца с прозрачностью. Заголовки, основной текст, отзывы, кнопки, маршрут и меню свёрстаны отдельными HTML-элементами. Отдельных оригиналов горного и группового снимков не было, поэтому детализация этих изображений ограничена качеством образца. Фотографии опубликованы с разрешения пользователя. Лицензии шрифтов находятся рядом с файлами шрифтов.

## Контакты и заявка

Кнопка «Оставить запрос» открывает форму. Она проверяет обязательные поля и готовит текст сообщения в браузере. Посетитель самостоятельно копирует и отправляет его Анастасии в Telegram. Данные не сохраняются и автоматически не передаются; серверного приёма заявок нет. Без JavaScript кнопка отправки отключена, чтобы данные не попали в URL.

Telegram: `https://t.me/inyfid`. Ссылка дополнительных отзывов: `https://t.me/anastasiadoroninaa`. Номер WhatsApp не предоставлен: кнопка открывает пояснение и доступный Telegram, без вымышленного номера.

Меню и диалоги работают с клавиатуры, закрываются по Escape; предусмотрены видимый фокус и системное уменьшение движения.

## Локальная работа

Нужны Node.js 20+ и Python 3. Зависимости npm не требуются.

```sh
npm run build
python -m http.server 4194 --bind 127.0.0.1 --directory out
```

Открыть `/`. Параметр `?capture=1` дожидается изображений и шрифтов для визуальной проверки. После крупных изменений и перед push:

```sh
npm run check
npm test
git diff --check
```

Статическая проверка охватывает локальные ресурсы, якоря, синтаксис CSS/JavaScript и отсутствие старых галерей в публикации. Тесты проверяют сохранность контакта и контекста заявки. Визуальная проверка, сравнение с образцом и работа кнопок выполняются отдельно в браузере. Снимки итераций и независимая критика хранятся локально в `../../reference-work/` и не публикуются.
