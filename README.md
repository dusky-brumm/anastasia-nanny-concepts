# Анастасия — 15 улучшенных вариантов и архив 26 прежних

[Открыть коллекцию](https://dusky-brumm.github.io/anastasia-nanny-concepts/collection.html).

Основная коллекция содержит 15 отобранных и улучшенных вариантов с разными палитрами, шрифтами и компоновками. Все 26 прежних сохранены в архиве. В коллекции есть поиск, фильтры, избранное, сравнение любой пары из 41 страницы и ссылки «до / после». Превью и полные скриншоты сняты с настоящих страниц.

## Страницы и исходники

- `dist/collection.html` — финальные 15; `dist/archive.html` — прежние 26.
- `dist/screenshots.html` — три итоговых набора, первичные наборы и краткий разбор исправлений.
- `dist/compare.html` — сравнение всех 41 варианта, включая «до / после».
- `dist/final/27-sky.html` … `41-choice.html` — финалисты, отображаемые как 01–15. Новые ID сохраняют раздельное избранное старых и новых страниц.
- `src/curated/` — каталог, шаблоны и сборка финалистов; `dist/final/final.css` и `heroes.css` — стили.
- `dist/studio/07-linen.html` … `26-agreement.html` — двадцать прежних направлений.
- `dist/index.html?concept=air|editorial|warm` — первые три варианта.
- `dist/directions.html?concept=close|letter|mosaic` — варианты 04–06.
- `src/studio/` — содержание, каталог, композиции и HTML-шаблоны.
- `dist/studio/studio.css` и `layouts.css` — общие и индивидуальные стили; генератор их сохраняет.
- `dist/shared-ui.js` — меню, диалоги и подготовка заявки. `preferences.js` сохраняет только идентификаторы избранных дизайнов.

Во всех финалистах единая последовательность: хедер с меню, первый экран, подробности услуги, об Анастасии, этапы с результатом для семьи, стоимость и условия, отзывы, заявка «Готовы обсудить подбор?», футер с контактами. Палитры включают голубой, терракоту, сливу, кобальт, чернильный, глину, охру, сепию, сирень, teal, шалфей, бордо, фисташковый и коралл. Счётчиков «40+» и «500+» нет.

Все 26 исходных вариантов были сняты на компьютере и телефоне и переданы трём агентам для независимой критики. После переработки все 15 финалистов прошли повторную визуальную критику и исправления. Полные исходные JPG и разборы находятся в локальной папке `project-notes/curation-2026-10-26/` (не публикуется в Git).

Фотографии извлечены из предоставленного PDF и опубликованы с разрешения пользователя. Размытые вырезки из старого макета заменены на исходные WebP. Отзывы, цены и условия из присланных материалов помечены как черновые и требуют подтверждения перед рабочим запуском.

## Формы

Форма проверяет поля и готовит текст заявки в браузере. Его можно скопировать и самостоятельно отправить в Telegram. Автоматической отправки, хранения контактных данных и аналитики нет. Без JavaScript кнопка формы отключена: данные не должны попадать в URL статического хостинга. Выбор консультации и подсказки для первого разговора переносятся в заявку с сохранением уже введённого текста.

Для коммерческого запуска ещё нужны подтверждённый адрес личной связи, получение заявок на сервере и согласованные сведения и документы об обработке данных. Текущий диалог объясняет работу демонстрационной формы.

## Локальная работа

Зависимости npm не требуются. Нужны Node.js 20+ и Python 3 для статической проверки.

```sh
npm run build
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

Открыть `/collection.html`. Готовую папку `dist/` можно раздавать любым статическим хостингом. Кириллические шрифтовые пары загружаются с Google Fonts; предусмотрены системные замены.

После крупных изменений и перед push:

```sh
npm run check
npm test
git diff --check
```

Проверка охватывает локальные ссылки, изображения, подписи полей, HTML-структуру, отключение отправки до инициализации, синтаксис JavaScript, девять разделов в правильном порядке, различия палитр и контраст основного/вторичного текста и кнопок. Тесты проверяют сохранность текста заявки и поведение избранного при заблокированном хранилище.

Визуальная проверка проводится отдельно в браузере на 1280, 768, 390 и 320 пикселях, с проверкой форм, меню, диалогов, фильтров и сравнения. Итоговые скриншоты для показа — в `dist/final/screens/`, превью — в `dist/final/previews/`, наборы — в `dist/final/sets/`. `scripts/prepare-curated-previews.py` (Pillow) готовит их из браузерных JPG. Старый `prepare-previews.py` обслуживает архивные направления.

GitHub Pages публикуется из корня ветки `codex/github-pages`, получаемой через `git subtree split --prefix=dist`. Исходники находятся в `main`.
