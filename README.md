# Анастасия — 26 направлений сайта

[Открыть коллекцию](https://dusky-brumm.github.io/anastasia-nanny-concepts/collection.html).

Двадцать новых самостоятельных композиций 07–26 и шесть предыдущих вариантов. В коллекции есть поиск, фильтры, избранное на устройстве и сравнение двух страниц с отдельной ссылкой на выбранную пару. Для превью используются скриншоты реальных страниц.

## Страницы и исходники

- `dist/collection.html` — вся коллекция, `dist/compare.html` — сравнение.
- `dist/studio/07-linen.html` … `26-agreement.html` — двадцать новых направлений.
- `dist/index.html?concept=air|editorial|warm` — первые три варианта.
- `dist/directions.html?concept=close|letter|mosaic` — варианты 04–06.
- `src/studio/` — содержание, каталог, композиции и HTML-шаблоны.
- `dist/studio/studio.css` и `layouts.css` — общие и индивидуальные стили; генератор их сохраняет.
- `dist/shared-ui.js` — меню, диалоги и подготовка заявки. `preferences.js` сохраняет только идентификаторы избранных дизайнов.

Новые варианты различаются композицией первого экрана, сетками, порядком и подачей блоков. Общая основа — голубой и белый, зелёные акценты, прямоугольные фотографии и вовлечённый подбор под конкретную семью. Счётчиков «40+» и «500+» нет.

Фотографии извлечены из предоставленного PDF и опубликованы с разрешения пользователя. Размытые вырезки из старого макета заменены на исходные WebP. Отзывы, цены и условия из присланных материалов помечены как черновые и требуют подтверждения перед рабочим запуском.

## Формы

Форма проверяет поля и готовит текст заявки в браузере. Его можно скопировать и самостоятельно отправить в Telegram. Автоматической отправки, хранения контактных данных и аналитики нет. Без JavaScript кнопка формы отключена: данные не должны попадать в URL статического хостинга. Выбор консультации и подсказки для первого разговора переносятся в заявку с сохранением уже введённого текста.

Для коммерческого запуска ещё нужны подтверждённый адрес личной связи, получение заявок на сервере и согласованные сведения и документы об обработке данных. Текущий диалог объясняет работу демонстрационной формы.

## Локальная работа

Зависимости npm не требуются. Нужны Node.js 20+ и Python 3 для статической проверки.

```sh
npm run build
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

Открыть `/collection.html`. Готовую папку `dist/` можно раздавать любым статическим хостингом. Шрифты Lora, Prata, Manrope и Caveat загружаются с Google Fonts; предусмотрены системные замены.

После крупных изменений и перед push:

```sh
npm run check
npm test
git diff --check
```

Проверка охватывает локальные ссылки, изображения, подписи полей, HTML-структуру списков, отключение отправки до инициализации, синтаксис JavaScript и структурные различия композиций. Тесты проверяют сохранность текста заявки и поведение избранного при заблокированном хранилище.

Визуальная проверка проводится отдельно в браузере на 1280, 768, 390 и 320 пикселях, с проверкой форм, меню, диалогов, фильтров и сравнения. Полные рабочие скриншоты хранятся локально; облегчённые превью — в `dist/studio/previews/`. Для подготовки новых превью из браузерных снимков есть `scripts/prepare-previews.py` (Pillow).

GitHub Pages публикуется из корня ветки `codex/github-pages`, получаемой через `git subtree split --prefix=dist`. Исходники находятся в `main`.
