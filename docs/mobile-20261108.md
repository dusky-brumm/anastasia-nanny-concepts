# Mobile refinement, 8 November 2026

Keep the approved nine blocks, Lora + Manrope, Caveat signature, milk/blue/sage palette and original artwork. There are no new design selectors.

The old home eagerly loaded nine iframe documents and waited for window load, images and every requested font before settling layout. The current home prioritizes header and hero, lazily loads later blocks, fits each block as soon as its DOM is ready and observes subsequent size changes. Font loading no longer gates first paint. A requested section waits for text metrics, with a bounded fallback, so an anchor stays accurate without waiting for photographs.

`frame-layout.js` owns sizing, open-menu extents, section navigation and draft reveal. Its code and the other small parent modules are emitted as one self-contained `site-base.js` request. A classic notification after each block's markup permits fitting before its decorative modules and images finish. The final runtime no longer includes the archived frame assembler. Embedded blocks use the page's single scrollbar. The header container permits its open navigation to remain visible. Escape, outside interactions and section links close the menu.

Responsive initial heights reserve the complete first photograph before the parent script arrives. Decorative strokes remain statically complete until the parent can drive their animation. A second local delay test held the parent script for 30 seconds: at 390 px, the reserved header and hero heights were 68 and 730 px, and the photo caption ended at 690 px inside the 730 px frame.

`site-responsive.css` contains the mobile adjustments. Service and process illustrations sit beside their headings, with descriptions below across the available width. Story controls have 44 px hit areas, payment cards are more compact, review tracks follow the active card height, form inputs use 16 px type and the privacy dialog fits the viewport. Desktop section compositions remain intact.

Local WOFF2 derivatives retain Cyrillic, Latin, punctuation, currency and arrows for Manrope. The small Caveat subset contains the confirmed signature. Original font files and licenses remain in source. Original illustrations also remain in source; published derivatives live in `src/site/media`. The artwork's SVG coordinates use a 1536 × 1024 plane, while the existing WebP sheets are 900 × 600, so crop coordinates must be scaled before encoding. The SVG image origin and logical dimensions preserve the original framing.

QA artifacts and the reproducible asset helpers are in `artifacts/mobile-polish-20261108` at the workspace root, outside this checkout. FontTools is an authoring tool there; it is not a runtime dependency. The normal build uses the committed derivatives and needs only Node.

Validation:

- Viewports: 320 × 800, 360 × 800, 390 × 844, 430 × 900, 768 × 1024, 844 × 390, 1024 × 768 and 1440 × 900. No horizontal document overflow. Phone and tablet buttons meet the 44 px target used in this refinement.
- Menu expansion, Escape, section navigation, four About slides, all three reviews, review Home/End keys, prepared request text, focus on the draft, privacy opening and closing were checked in the browser.
- A separate local server delayed raster images for 30 seconds. The home became ready and its application link remained usable while the portrait was incomplete. The application section settled at 8 px from the viewport top before the photograph loaded.
- The public payload fell from 4,972,105 bytes / 111 files to about 1.74 MB / 88 files. This is a byte-size comparison, not a measured Core Web Vitals score. The check script enforces a 2 MB budget, compact fonts, two eager blocks and no extra parent module requests.
- Browser QA uses Chrome viewport overrides. Actual iOS/Safari hardware was not used.
