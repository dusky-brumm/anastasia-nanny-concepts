# Three rebuilt layouts — 26 October 2026

The client rejected the previous collection as visually inconsistent and too wide. This series starts from new HTML/CSS presentation code in `src/restart/` and `dist/restart/`, using only the existing approved photos, factual copy and browser-local form behavior. It does not import earlier presentation styles.

The owner implemented 01-blue first. A fresh agent then implemented 02-sage from its own written brief. After that completed, another fresh agent implemented 03-paper. Both received the shared constraints and factual content, without the previous design history.

- **Тихое утро**: blue split introduction, rectangular portrait, one small quotation, open service and process grids.
- **Близкий круг**: centered introduction, one wide photo, light sage, repeated horizontal rows.
- **Личная история**: portrait on the left, warm paper, a repeated heading/content grid and restrained blue details.

All use Lora for headings and Manrope for body text. All nine client sections remain in the same order. The common page shell is capped at 1120px and its content at 1008px. Browser measurements confirmed the 1120px cap at both 1920px and 2560px; each page also passed 768px, 390px and 320px overflow checks. The site root opens `restart.html`; saved earlier designs remain available.

The full pages were captured at desktop and mobile sizes, then reviewed and recaptured after corrections. Corrections included preserving spaces around hidden mobile line breaks, keeping both faces inside the third portrait, and increasing small type in the second and third layouts. Original frames, measurements and review notes are in ignored `project-notes/restart-2026-10-26/`; publishable previews and full screenshots are in `dist/restart/`.

Validation includes all local links/assets/modules, the nine-section sequence, grounded prices/biography, a regression check for words separated by visual line breaks, menu and consultation selection, local draft creation, and gallery navigation. The forms prepare a local Telegram draft and do not claim to send requests.
